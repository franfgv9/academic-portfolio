# Publicar la copia independiente

Repositorio propuesto: `franfgv9/academic-portfolio`, público, con rama `main`.

1. Crea el repositorio vacío en tu cuenta de GitHub con el nombre `academic-portfolio`. No añadas README, `.gitignore` ni licencia desde el formulario, porque la copia local ya contiene los archivos preparados.
2. Desde la carpeta local `academic-portfolio`, conecta y sube esta copia:

```powershell
git remote add origin https://github.com/franfgv9/academic-portfolio.git
git push -u origin main
```

La publicación requiere autenticación de GitHub en el equipo. No compartas contraseñas o tokens en el chat. Si ya existe un remoto, comprueba su destino antes de modificarlo.

3. Abre el repositorio sin iniciar sesión y verifica la portada, las seis páginas y sus imágenes.
4. Añade a LinkedIn los enlaces y textos de [LINKEDIN_FEATURED.md](LINKEDIN_FEATURED.md). Las imágenes están en `assets/`: una general y una por proyecto, todas de 1200×630 px. El banner horizontal de la portada de GitHub es un archivo diferente, de 1200×300 px.

Estos pasos solo publican el repositorio nuevo. La copia no tiene el repositorio original como remoto y no escribe en tu README de perfil. FranCV Copilot no forma parte del contenido.
